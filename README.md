# BOT-22 🧠 — بوت تليجرام ذكي بذاكرة دائمة على GitHub

بوت تليجرام يتحدث معك عبر **Groq** (سرعة فائقة)، ويتعلم من كل تفاعل، ويحفظ ذاكرته بشكل دائم في ملف `knowledge_base.txt` على هذا المستودع، ويستخدم **بحثاً دلالياً (RAG)** لاسترجاع ما تعلمه عند كل سؤال.

## المكدس
- **FastAPI** + **pyTelegramBotAPI** (ويب هوك)
- **Groq** (LLM — الافتراضي `qwen/qwen3.8-27b`)
- **Sentence-Transformers** (`all-MiniLM-L6-v2`) للتضمين الدلالي
- **GitHub Contents API** لحفظ الذاكرة تلقائياً

## المميزات
- ✅ ذاكرة دائمة تُزامن مع GitHub في خيط خلفي (مع تأجيل ذكي لتجنب ضرب الـ API)
- ✅ بحث دلالي حقيقي عما تعلمه + أحدث السجلات (لا مجرد آخر 10 أسطر)
- ✅ ضبط تلقائي للويب هوك عند الإقلاع عبر `WEBHOOK_URL`
- ✅ أوامر: `/start` ، `/status` ، `/reset`
- ✅ معالجة آمنة للرسائل غير النصية، ومعالجة أخطاء Groq
- ✅ إمكانية تعطيل التضمين الثقيل (`EMBEDDINGS_ENABLED=false`) على الخوادم ضعيفة الذاكرة

## الإعداد المحلي
```bash
pip install -r requirements.txt
cp .env.example .env   # ثم املأ المتغيرات
uvicorn main:app --reload
```

## النشر على Render (موصى به)
1. ادفع هذا المستودع (هو جاهز).
2. في Render: **New → Web Service** → اختر المستودع.
3. Render سيقرأ `render.yaml` تلقائياً.
4. أضف المتغيرات السرية من لوحة Render (Environment):
   - `TELEGRAM_BOT_TOKEN`
   - `GROQ_API_KEY`
   - `GITHUB_TOKEN` (صلاحية `repo`)
   - `GITHUB_REPO=eo7w/BOT-22`
   - `WEBHOOK_URL=https://<اسم-تطبيقك>.onrender.com`
5. بعد أول إقلاع، يضبط البوت الويب هوك بنفسه ويعمل.

> ملاحظة: النطاق المجاني في Render ذاكرته 512MB. إذا تعطل التطبيق بسبب `OOM`، عيّن `EMBEDDINGS_ENABLED=false` (سيستخدم بحثاً بالكلمات المفتاحية بدلاً من التضمين).
